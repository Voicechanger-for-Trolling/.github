Before you troll, keep these things in mind.

- **Virtual Microphone is required.** All these tools work by installing a virtual mic. You must select it as your input device in Discord, the game, or the call app [citation:2][citation:3].
- **Latency varies.** Voicemod is optimized for low latency [citation:14]. Mootboard claims ≤15 ms [citation:3]. Clownfish can occasionally hang or glitch [citation:1]. Test before you commit to a prank.
- **Free vs Pro.** Voicemod's free tier has a rotating selection of voices; the Pro tier unlocks the full library [citation:10]. Clownfish is fully free. Mootboard is open-source and free [citation:3].
- **Platform limits.** Clownfish is Windows-only [citation:1]. Mootboard supports Windows and macOS [citation:3]. Voicemod supports Windows and macOS [citation:1].
- **Troll responsibly.** Voice changers and soundboards are for fun. Don't use them to harass, impersonate, or deceive in harmful ways. The best pranks are the ones everyone laughs at—including the target.
